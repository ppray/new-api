
## 三、日常更新流程

### 改了前端代码后

**本地电脑：**

```bash
# 1. 开发调试
cd web && bun install && bun run dev

# 2. 提交代码
git add .
git commit -m "feat: 你的改动说明"
git push origin main

# 3. 构建并推送镜像
cd ..
docker build -t ppraydo/new-api:latest .
docker push ppraydo/new-api:latest
```

**服务器：**

```bash
cd /root/new-api && docker compose pull new-api && docker compose up -d new-api
```

### 同步上游更新

```bash
# 本地
git fetch upstream
git merge upstream/main
# 如有冲突，解决后提交
git push origin main

# 重新构建镜像
docker build -t ppraydo/new-api:latest .
docker push ppraydo/new-api:latest
```

## 四、注意事项

1. Docker Hub 免费账号支持 1 个私有仓库或无限公开仓库
2. 服务器上的 2GB swap 可以保留（`/swapfile`），日常运行用不到，但更新时可能有用
3. 构建镜像时 Docker Desktop 默认分配 2GB 内存，如构建失败可在 Docker Desktop → Settings → Resources 中调大到 4GB
4. 建议给镜像打版本标签（如 `v1.0.0`），方便回滚：
   ```bash
   docker tag ppraydo/new-api:latest ppraydo/new-api:v1.0.0
   docker push ppraydo/new-api:v1.0.0
   ```
